# ex_axios

Лекція 15 «REST. HTTP. Express» (HTTP-клієнт). Запит до публічного GitHub API через `axios`.

| Файл | Що показує |
| --- | --- |
| `api.js` | `axios(options)` з URL і заголовком `User-Agent`; друкує `data`, `status`, `statusText`, заголовки й конфіг відповіді |
| `index.js` | викликає `api()` і друкує результат або помилку |

## Запуск

```bash
cd ex_axios
npm ci
node index.js      # потрібен вихід в інтернет
```

## Залежності

`axios@1.21.0` (точна версія; оновлено 2026-10-31 з `axios@0.18.1`, який мав 2 high-
вразливості в `axios` і `follow-redirects`, а вся гілка 0.x досі вразлива). `npm audit`:
0 вразливостей. Код змінювати не довелося: `axios(options)` і поля відповіді ті самі.
Пакета `request` тут немає (рядок `'User-Agent': 'request'` лише значення заголовка).

## Стан на Node 24.14.1

Працює (перевірено 2026-10-31 до й після оновлення): GitHub відповідає 200 `OK`, код
виходу 0. Для нового коду можна обійтися вбудованим `fetch` (Node 18+).

## Відомі проблеми

- `api.js:19-35`: проміс `axios` загорнуто в `new Promise` (зайвий шар), а `:33`
  `reject()` без аргументу: виклик у `index.js:6-8` отримує `undefined` замість помилки.
- `api.js:26-27`: у консоль іде весь об'єкт заголовків і `config`; у реальному коді там
  можуть бути токени.
