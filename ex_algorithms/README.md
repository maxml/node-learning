# ex_algorithms

Лекція 12 «Алгоритми. Таймери». Класичні алгоритми без залежностей; кожен файл одразу друкує
результати демо-викликів.

| Файл | Що показує |
| --- | --- |
| `euclidian.js` | НСД: ітеративний варіант відніманням і рекурсивний через `%` |
| `factorial.js` | факторіал циклом і рекурсією, вихід за межі `Number` на 171! |
| `fibonacci.js` | послідовність Фібоначчі масивом і n-те число циклом, аж до `Infinity` |
| `kmp.js` | пошук підрядка Кнута–Морріса–Пратта (таблиця префіксів) |
| `lcs.js` | найдовша спільна підпослідовність динамічним програмуванням |

## Запуск

```bash
cd ex_algorithms
node fibonacci.js   # або будь-який інший файл
```

## Стан на Node 24.14.1

Усі п'ять файлів запускаються й завершуються з кодом 0.

## Відомі проблеми

Відтворено скриптом `../algorithms/old-examples-bugs.js`, який лише читає ці файли.

- `fibonacci.js:13`, `:42`: `while (iterationsCounter)` при `n = 0` стартує з `-1` і не
  зупиняється; `fibonacciNth(0)` зависає.
- `fibonacci.js:43`: арифметика на `Number`; з F(79) значення неточне
  (14472334024676220 замість …221), з F(1477) `Infinity`. Точний варіант потребує `BigInt`.
- `factorial.js:8-9`: неточно вже з 23!, `Infinity` з 171!; `factorialRecursive(-5)`
  (`:2`) повертає 1 замість помилки.
- `euclidian.js:6`: ітеративна версія віднімає, а не бере остачу, тому працює за
  O(max/min): `gcd(1e8, 1)` займає сотні мілісекунд проти мікросекунд у рекурсивної.
  Нецілі аргументи приймаються мовчки.
- `kmp.js:37`: повертає лише перше входження (на 200 000 випадкових випадках збігається
  з `indexOf`, тобто для першого входження коректний).
- `lcs.js:14`, `:37`, `:49`: налагоджувальні `console.log` усередині функції; `:30` для
  порожньої відповіді повертає `['']`, масив довжини 1.
